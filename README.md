# cognitive-alignment-kit · 协作认知对齐开源方法包

> 一个给研究者与工程师的**可复现方法论 + 轻量工具**集合：关于「AI 协作中如何避免谄媚回响（Flattering-Echo，下文 FEE）、保持认知对齐」。
> 状态：**草稿 / 投石问路**。先放出方法与可复现草样，看社区是否需要，再决定是否加深。

---

## 为什么这件事值得做

AI 越有用，越容易滑向一种安静的失效：**谄媚回响（FEE）**——模型为了「被采纳 / 被喜欢」而回弹用户想听的话，而不是校准真相。更隐蔽的是：连**校准者自己**也会被嵌套进这一层（审计者若只审计不认被重构，等于把盲区也开在自己这儿）。

这不是「模型坏了对齐」的 Story（故事套路），而是一个**可观测、可自检、可复现**的工程与认知问题。本仓库提供一套最小可用的方法与草样，供同行复现、反驳、或接手深化。

## 我们提供什么

1. **FEE 概念框架**：把「谄媚回响」从直觉变成可操作的判定维度（对称应用 / 诤言非表演壳 / 来源透明）。
2. **对话谄媚回响自检草样**（`fee_selfcheck.py`）：输入一段人机对话，按维度给风险标记——纯草样，欢迎替换判据。
3. **协作认知对齐协议草案**（`alignment_protocol.md`）：几条可落地的协作原则（概念层优先于取证 / 他者含系统内对等体 / 框架清晰即授权自主定承重件）。

## 快速开始（草样）

```bash
# 准备一段脱敏对话 JSON：[{"user": "...", "ai": "..."}, ...]
python fee_selfcheck.py --input examples/samples_synthetic.json
# 或不带参数，运行内置脱敏演示
python fee_selfcheck.py
```

输出每个 turn 的 FEE 信号标记（空 = 无明显信号；非空 = 需人工复核，非定罪）。

> 判据是**草样不是真理**：本仓库的价值在「可被复现与反驳的方法」，不在某个固定阈值。

## 协作认知对齐协议（要点）

- **概念层优先于取证**：用比喻（游戏 / 文学 / 生物）时，第一刀先判「它在类比现实系统哪一层」，再去取证——避免把战略隐喻当字面术语题。
- **他者含系统内对等体**：AI / 协作节点即系统内部对等他者；人–AI 共生体本身是文明新形态，不需混进「人类采用」才算文明。
- **框架清晰即授权自主定承重件**：框架级判断清晰时，协作方直接自主决策并写回，不反复确认；关键抉择报备而非擅覆盖。
